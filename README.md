# 法学引注助手

本工具命名取自《法学引注手册（第二版）》的官方英文名“Manual of Legal Citation” 缩写，并于缩写前添加 Chinese 以辨别具体规范地域，故得名 “**C**hinese **M**anual of **L**egal **C**itation”。

本工具按《法学引注手册（第二版）》把参考文献整理成脚注格式。手册要求、但原文缺少的资料，会标成 `[栏位名]`，工具不会自行编造。下为范例：

```plaintext
Input:   王名扬. 美国行政法[M]. 北京: 中国法制出版社: 18.
Output:  王名扬：《美国行政法》，中国法制出版社[年份]年版，第18页。
```

如有任何问题或建议，请在 GitHub 储存库的「Issues」中提出。

## 一、这个工具做什么

你把参考文献交给它，它会按《法学引注手册》（第二版）的规则整理成脚注格式。它会做三件事：

1. **改格式。** 例如加上书名号、删去出版地、把「1995: 18」改成「1995年版，第18页」、把法条中的「第一千二百二十四条」改成「第1224条」。
2. **标出缺项。** 手册要求、但你提供的资料里没有的内容，会以方括号加栏位名称显示，例如 `[出版社]`、`[页码]`。工具**不会编造**这些资料，你需要翻查原书补上。
3. **拒绝未经核实的文献。** 手册第 2 条规定，未经查核的文献不得引用。如你剔选「来源尚未核实」（例如文献是 AI 工具提供的），工具会提醒你先找原文。

它**不会**替你判断引用是否恰当，也不会检查文献是否真的存在。最终仍以手册原文和原书为准。

工具支援以下文献：

- **中文**：图书、期刊论文、文集或集刊文章、报纸文章、网络文献、微信公众号文章、学位论文。
- **法律与案例**：法律法规、规范性文件、裁判文书、公报案例、指导性案例、人民法院案例库案例。
- **英文**：图书、期刊论文、美国案例、英国案例。
- **其他外文**：法文、德文、意大利文、俄文、日文的图书和期刊论文。

## 二、网页版：不用安装，开启即用

用浏览器（Chrome、Edge、Safari、Firefox 均可）开启工具的网址便可，手机亦适用。

页面左边是**输入区**，右边是**结果区**。输入有三种方式，用左上角的三个分页切换。

### 方式一：贴上原文

适合手上已有一批写好的参考文献、只是格式不对的情况。

1. 按「粘贴原文」分页。
2. 把参考文献贴到大方框内，**每行一条**。
3. 按「转换」。

可自动识别的写法见第四部分。识别不到的那一行会显示「无法转换」，这时请改用方式二。

### 方式二：逐项填写

适合只有零散资料，或原文格式太乱的情况。

1. 按「逐项填写」分页。
2. 在「文献类型」中选择类型，例如「中文图书」「期刊论文」「裁判文书」。
3. 逐格填写。**有 \* 号的是手册要求的资料**，不知道可以先留空，结果中会标成方括号栏位。
4. 按实际情况剔选下方的方格，例如：
    - 「译著（必须写译者）」：外国书的中译本要剔选。
    - 「引用了具体内容（必须标页码）」：引用了书中某句话或某个观点时要剔选。
5. 按「生成引注」。

填写小贴士：

- 中文和日文作者之间用顿号分隔：`高鸿钧、程汉大`。
- 西文和俄文作者之间用分号分隔，每位写「名 姓」：`Stephen J. Choi; A. C. Pritchard`。
- 法条的条、款、项可以写汉字，也可以写数字，工具会统一改成数字。

### 方式三：整篇文章

适合文章已经写好、脚注格式五花八门的情况。

1. 按「整篇文章」分页。
2. 按「选择文件」上传文章，或把全文贴到方框内。可以上传：
    - Word 文件（.docx）：读取 Word 的脚注，取回的是一份修订后的 Word 文件；
    - .doc、.pages、.odt、.rtf：网页版打不开，请先另存为 .docx（Word：「文件 → 另存为」选「Word 文档（.docx）」；Pages：「文件 → 导出为 → Word」）。命令行版本在装有 LibreOffice 时可以直接处理这些格式，见下文；
    - Markdown 文件（.md）：读取 `[^1]: ……` 形式的脚注，正文不动；
    - 纯文字档（.txt）：每行一条注释，行首的 `[1]`、`1.`、`①` 等编号会保留。
3. 按「处理脚注」（上传文件会自动处理）。
4. 核对右边的结果，然后按「下载修订稿」取回改好的文章，或按「全部复制」。Word 文件按「下载修订后的 Word 文件」，取回的文件正文和版式不变，只改脚注：
    - 默认勾选「以修订模式标出改动」，每条改动在 Word 中以「修订」显示（作者为「引注整理」），可以逐条接受或拒绝，也可以在「审阅」中一次全部接受；
    - 不勾选则直接替换，不留修订痕迹；
    - 改写过的脚注沿用原来的字体字号，英文篇名改为斜体；没有改动的脚注原样不动。

工具对每条脚注会这样处理：

- **逐一改写其中的文献。** 一条脚注引了几种文献（用「；」分开）的，分别改写。法律省略「中华人民共和国」并只注明最后一次修订或修正（第67、69条）；规范性文件写成「制定机关《文件名》，文号」，没有文号的写发布日期（第72–74条）；论文加「载」；「頁77起」改为「第77页以下」；台港习惯的〈篇名〉改为《篇名》。
- **作者自己的话原样保留。** 脚注中的说明、引文（「……」）和〔有待核对〕之类的自注都不改。自注显示来源尚未核实的，会提示手册第2条的要求。
- **交叉引用写成完整引注。** 「同上」「上注5」「《某法》（上注5）第3条」「第493号令（上注9）第46条」会改写成完整的引注，并换上新的条文或页码。手册第13条不建议在定稿前使用略写，以免改稿时编号错乱。前注识别不了的，写成手册的「同前注[5]，……」。
- **繁体文章仍输出繁体。** 工具在内部按简体识别，输出时沿用作者的用字。
- **识别不了的部分保留原文。** 例如只写「新华社某日报道」而没有标题的新闻、没有书名号的官方通报，工具无从判断题目和出处，会原样保留并标为「保留原文」，请人工补齐。

### 看懂结果

每条结果下方先标出工具识别到的**文献类型**，例如「法律法规」「规范性文件」「期刊论文」「中文图书」「网络文献」；整篇文章中一条脚注引了几种文献的，会逐一列出，交叉引用标为「交叉引用」。类型不对（例如把法律当成了图书），说明原文被读错了，请改用「逐项填写」。

类型之后还有一个小标签：

| 标签             | 意思                              | 你要做什么                     |
| ---------------- | --------------------------------- | ------------------------------ |
| 绿色「要素齐全」 | 手册要求的资料齐备                | 可直接使用                     |
| 黄色「缺 N 项」  | 有 N 项资料缺失，正文中以黄色标示 | 翻查原书，补上方括号内的内容   |
| 红色「无法转换」 | 原文格式识别不到，或来源未经核实  | 改用「逐项填写」，或先核实来源 |

「整篇文章」的标签：

| 标签                           | 意思                     | 你要做什么                                         |
| ------------------------------ | ------------------------ | -------------------------------------------------- |
| 绿色「已按手册改写」           | 脚注中的文献都已改写     | 看一眼「原文」，确认无误                           |
| 黄色「部分改写，其余保留原文」 | 有些文献认得，有些认不得 | 补改保留原文的部分                                 |
| 灰色「未识别，保留原文」       | 整条脚注都没有改动       | 如果其中有文献，请人工改写；纯说明性的脚注不用理会 |

### 复制到 Word

- 按单条结果旁的「复制」，或按右上角的「全部复制」。
- 在 Word 中直接贴上，英文书名和文章名会保留斜体。
- 如果浏览器不允许复制，页面会提示你手动选取文字再复制。

页面会在你的浏览器中记住上次贴上的内容；换一部电脑或清除浏览器资料后便会消失。内容不会上传到任何伺服器。

## 三、遇到方括号栏位时去哪里找资料

| 栏位                    | 去哪里找                                                       |
| ----------------------- | -------------------------------------------------------------- |
| `[出版社]` `[出版年份]` | 图书的版权页（通常在书名页背面），以版权页为准（手册第 26 条） |
| `[译者]`                | 版权页或封面上的「××译」                                       |
| `[页码]`                | 你所引用的那句话所在的页                                       |
| `[期次]` `[年份]`       | 期刊封面或论文首页的页眉                                       |
| `[月]` `[日]` `[版面]`  | 报纸版面顶端的日期和版次                                       |
| `[案号]` `[文书类型]`   | 裁判文书首页，例如「（2018）京0108民初142号」「民事判决书」    |
| `[修订或修正年份]`      | 法律文本标题下方的修改说明，例如「2013年12月28日修正」         |
| `[上传日期]`            | 网页标题下方的发布时间；实在没有，就写浏览日期                 |
| `[作者名]`              | 英文作者的名字（不是姓氏），见书名页                           |
| `[编者身份]`            | 文集封面或版权页上的「主编」「编」「编译」                     |
| `[网站名]`              | 网页所属的网站，例如「人民网」（国标格式不写，但手册要求写）   |
| `[博士/硕士]`           | 论文封面上的学位级别                                           |
| `[巻号]`                | 日文期刊的卷号和期号，见期刊封面                               |

## 四、能自动识别的原文写法

「粘贴原文」认得以下写法，每种写法的完整例子见第十部分第 18 条起。认不出的那一行会显示「无法转换」，请改用「逐项填写」。

### 中文

| 写法                                | 例子                                                                             |
| ----------------------------------- | -------------------------------------------------------------------------------- |
| 国标 GB/T 7714 图书 [M]（包括译著） | `[美]富勒. 法律的道德性[M]. 郑戈, 译. 北京: 商务印书馆, 2005.`                   |
| 国标期刊 [J]                        | `季卫东. 法律程序的意义[J]. 中国社会科学, 1993(1): 91.`                          |
| 国标报纸 [N]                        | `何海波. 判决书上网[N]. 法制日报, 2000.`                                         |
| 国标学位论文 [D]                    | `某某. 题目[D]. 北京: 中国政法大学, 2010.`                                       |
| 国标析出文献 [C]//                  | `王保树. 篇名[C]//梁慧星, 主编. 民商法论丛: 第1卷. 北京: 法律出版社, 1994: 110.` |
| 国标网络文献 [EB/OL]                | `标题[EB/OL]. (2024-10-12)[2024-10-20]. http://…`                                |
| 「作者《书名》」加零散资料          | `张新宝《侵权责任法》第5版 73-75页`                                              |
| 已接近手册格式的引注（用来复查）    | `季卫东：《法律程序的意义》，载《中国社会科学》1993年第1期，第91页`              |
| 法条                                | `中华人民共和国民法典 第一千二百二十四条第一款第（一）项`                        |
| 带文号的规范性文件                  | `国务院关于在全国建立农村最低生活保障制度的通知 国发(2007)19号`                  |
| 裁判文书                            | `某某诉某某案，某某人民法院（2020）京01民终123号民事判决书`                      |
| 公报案例                            | `某某案，最高人民法院公报 2015-11`                                               |
| 指导性案例                          | `指导案例24号：某某案`                                                           |
| 人民法院案例库                      | `某某案，人民法院案例库 2023-01-2-087-001`                                       |

### 外文

| 语种                           | 例子                                                                                                 |
| ------------------------------ | ---------------------------------------------------------------------------------------------------- |
| 英文期刊（Bluebook）           | `Charles A. Reich, The New Property, 73 Yale L.J. 733, 737–38 (1964).`                               |
| 英文图书（OSCOLA 或 Bluebook） | `William P. Alford, To Steal a Book Is an Elegant Offense (Stanford University Press 1995) 98`       |
| 美国案例                       | `Natural Resources Defense Council v. Gorsuch, 685 F.2d 718 (D.C. Cir. 1982)`                        |
| 英国案例                       | `Ridge v Baldwin [1964] AC 40`                                                                       |
| 法文图书、论文                 | `CHEVALLIER (J.), L'État de droit, Paris, Montchrestien, 4e éd., 2003, p. 16-29`                     |
| 德文图书、论文                 | `Roxin, Claus: Strafrecht Allgemeiner Teil, Bd. I, 4. Aufl., München 2006, § 15 Rn. 19`              |
| 意大利文图书、论文             | `Falzea A., L'offerta reale e la liberazione coattiva del debitore, Milano, Giuffrè, 1947, p. 34 s.` |
| 俄文图书、论文                 | `Автор А. А. Название статьи // Государство и право. 2023. № 3. С. 17–30.`                           |
| 日文图书、论文                 | `我妻栄『新訂担保物権法』（岩波書店，昭和46年）50頁`                                                 |

请留意：

- 程式会把外文作者改为「名在前、姓在后」，删去出版地，并把日本年号换算成公元年份。
- 法文、德文、意大利文靠一些标志字词辨认语种（例如 éd.、Aufl.、Giuffrè、della）。如果一条法文文献里一个这类字词都没有，会被当作英文处理；这时请改用「逐项填写」，选择对应语种。
- 书名本身带逗号的西文文献可能会被拆错，请核对结果。
- 文集中的外文文章（带 in 的），暂时请用「逐项填写」。

「逐项填写」支援 27 种类型：

- 中文：图书、期刊论文、文集或集刊文章、报纸文章、网络文献、微信公众号文章、学位论文。
- 法律与案例：法律法规、规范性文件、裁判文书、公报案例、指导性案例、人民法院案例库案例。
- 英文：图书、期刊论文、美国案例、英国案例。
- 其他外文：法文、德文、意大利文、俄文、日文的图书和期刊论文。

## 五、进阶（可选）：在自己的电脑上大量转换

网页版已能应付大部分需要。如果你有几百条文献要处理，或想把结果储存成档案，可以使用命令列版本。命令列版和网页版用的是同一套程式，结果完全一样。你需要先安装 Node.js。

### 1. 安装 Node.js 及 tsx

- 开启 <https://nodejs.org/>，下载标示 **LTS** 的版本并安装，一直按「下一步」即可。
- 安装完成后，开启「命令列」：
  - Windows：按 `Win` 键，输入 `cmd`，再按 Enter 键。
  - Mac：开启「启动台」，搜寻「终端机」（Terminal）。
- 输入 `node --version` 再按 Enter 键。看到 `v22.18` 或更高的版本号，即表示安装成功。
- 输入 `npm install -g tsx` 再按 Enter 键，安装 tsx。

### 2. 进入工具所在的资料夹

在命令列输入 `cd` 和一个空格，然后把工具资料夹拖进命令列视窗，再按 Enter 键。

### 3. 转换

转换一条：

```zsh
tsx src/cli.ts --raw "王名扬. 美国行政法[M]. 北京: 中国法制出版社, 1995: 18."
```

大量转换：把参考文献存成一个纯文字档（例如 `refs.txt`，每行一条，以 UTF-8 编码储存），然后输入：

```zsh
tsx src/cli.ts --raw-file refs.txt
```

想把结果存成档案：

```zsh
tsx src/cli.ts --raw-file refs.txt > 结果.txt
```

文献类型和缺项会在荧幕上另起一行，以「类型：……」「缺少：……」提示，不会写进结果档案。

处理整篇文章（Markdown、纯文字或 Word）：

```zsh
tsx src/cli.ts --article 文章.md > 文章（修订稿）.md
tsx src/cli.ts --article 文章.docx            # 写出 文章.revised.docx，改动以修订标出
tsx src/cli.ts --article 文章.docx --clean    # 直接替换，不留修订痕迹
tsx src/cli.ts --article 文章.doc -o 定稿.doc  # .doc、.odt、.rtf、.pages 需要 LibreOffice
```

改好的文章写到 `文章（修订稿）.md`，正文不变；哪些脚注保留了原文、缺了什么、哪些来源尚未核实，会显示在荧幕上。Word 文件写出一份修订后的 Word 文件（默认为「原名.revised.docx」，可用 `-o` 指定）。.doc、.odt、.rtf 先由 LibreOffice 转为 .docx 处理，再存回原格式；.pages 存为 .docx。

### 4. 检查工具是否正常

```zsh
npm test
```

最后几行显示 `fail 0`，即表示一切正常。

## 七、转换范例

下面的原始文字是练习材料，模仿常见的混杂格式（GB/T 7714「学报体」、Bluebook 缩写、随手记下的笔记）。所引文献都来自手册自己的范例，没有虚构书目。
方括号内的栏位名（例如 `[出版社]`）表示手册要求、但原始文字没有提供的资料。程式不会替你填写，需要你核对原书后补上。

每条范例的「原始」和「转换」两行保留简体字：前者是输入，后者是程式应得的输出。自动测试会逐条核对这两行，修改时请保持「- 原始：」「- 转换：」的写法。

### 7.1 要素齐全的文字：直接转换

**1. 中文专著（学报体）**

- 原始：`王名扬. 美国行政法[M]. 北京: 中国法制出版社, 1995: 18.`
- 转换：王名扬：《美国行政法》，中国法制出版社1995年版，第18页。
- 改动：作者与书名之间用冒号，书名加书名号；删去 [M] 和出版地「北京」（第41条）；出版社与年份连写，并加「版」字；页码写作「第18页」（第48条）。

**2. 译著**

- 原始：`富勒（美）著，郑戈 译，法律的道德性，商务印书馆，2005`
- 转换：[美]富勒：《法律的道德性》，郑戈译，商务印书馆2005年版。
- 改动：国籍放在姓名前的方括号里（第33条）；删去「著」（第27条）；译者放在书名之后（第29条）。这里是整体提及全书，可以不标页码；如果是概括引用，在前面加「参见」（第48条）。

**3. 期刊论文**

- 原始：`季卫东."法律程序的意义——对中国法制建设的另一种思考", 中国社会科学, 1993(1): 91.`
- 转换：季卫东：《法律程序的意义——对中国法制建设的另一种思考》，载《中国社会科学》1993年第1期，第91页。
- 改动：文章名不用引号，改用书名号（第37条）；刊名前加「载」（第8条）；「1993(1)」写作「1993年第1期」（第43条）。

**4. 集刊中的文章**

- 原始：`王保树，股份有限公司机关构造中的董事和董事会，梁慧星主编，民商法论丛 第1卷，法律出版社 1994年，110页`
- 转换：王保树：《股份有限公司机关构造中的董事和董事会》，载梁慧星主编：《民商法论丛》第1卷，法律出版社1994年版，第110页。
- 改动：用「载」引出集刊，主编后面加冒号；卷次不加括号（第39、44条）。

**5. 法律条文**

- 原始：`中华人民共和国民法典 第一千二百二十四条第一款第（一）项`
- 转换：《民法典》第1224条第1款第1项。
- 改动：省略「中华人民共和国」（第67条）；条、款、项改为阿拉伯数字，去掉括号（第70条）。

**6. 规范性文件**

- 原始：`国务院关于在全国建立农村最低生活保障制度的通知 国发(2007)19号 第四部分第（一）点`
- 转换：《国务院关于在全国建立农村最低生活保障制度的通知》，国发〔2007〕19号，第四节第一小节。
- 改动：文号年份改用六角括号〔〕（第74条）；「一、（一）」式的分节写作「第×节第×小节」（第75条）。

**7. 公报案例**

- 原始：`陆红霞诉南通市发改委政府信息公开答复案，最高人民法院公报 2015-11`
- 转换：陆红霞诉南通市发展和改革委员会政府信息公开答复案，载《最高人民法院公报》2015年第11期。
- 改动：当事人名称写全称；公报案例可以不再引裁判文书（第90条）。

**8. 英文期刊论文（Bluebook 缩写）**

- 原始：`Charles A. Reich, The New Property, 73 Yale L.J. 733, 737–38 (1964).`
- 转换：Charles A. Reich, _The New Property_, 73 Yale Law Journal 733, 737-738 (1964).
- 改动：刊名不用缩写，写全称（第97条）；文章名改为斜体（第103条）；页码写完整，用短横线连接。

**9. 网络新闻（看起来缺日期，其实符合要求）**

- 原始：`人民网：全国打击治理农村诈骗工作现场会召开 http://society.people.com.cn/n1/2024/1012/c1008-40337761.html`

- 说明：连结里已经有日期 2024/1012，可以不再单独写上传日期（第53条）；来源没有署名的，不写作者（第52条）。如果原网页有署名记者，要补上。

### 7.2 缺少要素的文字：转换并标出缺项

**10. 专著缺出版资料**

- 原始：`张新宝《侵权责任法》第5版 73-75页`
- 转换：张新宝：《侵权责任法》（第5版），[出版社][出版年份]年版，第73-75页。
- 缺项：出版社和出版年份是图书的必要资料（第41条），应以版权页为准（第26条）。

**11. 报纸文章缺日期和版面**

- 原始：`何海波，判决书上网，法制日报，2000`
- 转换：何海波：《判决书上网》，载《法制日报》2000年[月]月[日]日，第[版面]版。
- 缺项：报纸要写年、月、日和版面，版面序号前不加 0（第45条）。

**12. 判决书缺案号**

- 原始：`包郑照诉苍南县人民政府强制拆除房屋案，浙江省高级人民法院，1988年判决`
- 转换：包郑照等诉苍南县人民政府强制拆除房屋案，浙江省高级人民法院（1988）[案号]号[文书类型]。
- 缺项：裁判文书要写法院全称、案号和文书类型（第87、89条）。原告有多人的，案名写第一人加「等」（第88条）；「包郑照等」需要你按判决书确认。如果引的是公报或其他权威来源，可以改引那个来源（第90条）。

**13. 外国译著缺译者、国籍和页码**

- 原始：`毛雷尔 行政法学总论 法律出版社 2000 年`
- 转换：[德]哈特穆特·毛雷尔：《行政法学总论》，[译者]译，法律出版社2000年版，第[页码]页。
- 缺项：译者是翻译作品的必要资料（第29条）；外籍作者要写全名和国籍（第32、33条），这里的名和国籍是根据手册第26条的例子补的，请再核对版权页；引用具体内容的要标页码（第48条）。

**14. 英文图书缺作者全名和页码**

- 原始：`Alford, To Steal a Book Is an Elegant Offense, Stanford UP 1995`（正文是直接引语）
- 转换：[作者名] Alford, _To Steal a Book Is an Elegant Offense: [副标题]_, Stanford University Press, 1995, p. [页码].
- 缺项：作者要写成名在前、姓在后的全名，不能只写姓或写成「Alford, W.」（第96、102条）；出版社写全称（第97条）；直接引用必须标页码（第48、107条）；有副标题的要保留（第3条）。

**15. 修改过的法律没有写版本**

- 原始：`公司法第16条`（正文讨论的是旧法规定）
- 转换：《公司法》（[修订或修正年份]）第16条。
- 缺项：引用修改过的法律，要注明所引版本的年份（第69条）。只有正文已经说明版本、从上下文可以判断时才能省略。

**16. 学位论文缺学位层级和年份**

- 原始：`某某：游走在上帝与凯撒之间——美国宪法第一修正案中的政教关系研究，中国政法大学`
- 转换：[作者]：《游走在上帝与凯撒之间——美国宪法第一修正案中的政教关系研究》，中国政法大学[答辩年份]年[博士/硕士]学位论文，第[页码]页。
- 缺项：要写授予单位、答辩年份和学位层级（第64条）；如果论文后来正式发表了，应改引发表版本。

**17. 来源无法核实（例如 AI 工具给出的文献）**

- 原始：`（ChatGPT 提供）某某：《数字行政中的算法问责》，载《法学研究》2021年第4期。`
- 处理：不转换。手册第2条规定，未经查核的文献不得引用，AI 工具给出的文献资料「尤须谨慎」。请先在知网或纸质期刊中找到原文，再按第3条的格式转换。
